# Demo notes (parked)

Decided 2026-10-11, set aside until the real app works. Build the real thing first; add these on top for the stage.

- **Replay**: "Start search" plays a pre-made `AgentRun` back over ~60–90s using the real call timestamps, sped up: counts climb, each finished call surfaces, shortlist rows fade in. "Skip to results" for rehearsals; `prefers-reduced-motion` jumps straight to results.
- **Pre-made calls**: placed beforehand with Dial and replayed from its recordings and transcripts (see `docs/design-brief.md` §9).
- **Sample household**: 4 housemates, $1,500–$2,200 each, Caltrain to the South Bay; one wants a dog (built-in pets conflict).
- **Sample run**: ~40 found, 14 called, 5 verified, 4 tours offered; ruled-out mix of scam, taken, wrong tenant, breaks must-have, no answer.
- **Calendars**: 2–3 test Google accounts connected ahead of time so OAuth doesn't eat stage time.
- **Live search**: one light browser-agent run as proof, on top of the curated listings.
- **Screen**: laptop on stage, desktop only.
